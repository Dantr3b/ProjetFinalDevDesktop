# Plan de réalisation GameVault

## Priorité 1 - Socle fonctionnel

- Projet Maven JavaFX.
- FXML + contrôleurs séparés.
- Entité `Game`.
- SQLite + Hibernate.
- CRUD complet.
- Recherche, filtres et tri.
- Validations et messages d'erreur.

## Priorité 2 - Expérience utilisateur

- Interface cohérente avec la maquette Figma.
- Navigation latérale stable.
- Détail de jeu lisible.
- Confirmation avant suppression.
- Données de démo au premier lancement.

## Priorité 3 - Livrables

- README clair.
- Lien vers Figma.
- Document de justification UX/UI.
- Configuration externalisée.

## Bonus possibles

- Export CSV.
- Export PDF.
- Import automatique depuis une API de jeux vidéo.
- Packaging JAR prêt à lancer.
